# JuliFit
PWA de nutrición con análisis visual de comida, códigos de barras, Coach IA y análisis de progreso.

## Vercel
1. Conecta este proyecto a Vercel.
2. Añade `OPENAI_API_KEY` en Environment Variables.
3. Opcional: `OPENAI_MODEL`.
4. Deploy.

La cuenta incluida en esta versión es un prototipo local; no debe considerarse autenticación segura ni sincronización entre dispositivos.
